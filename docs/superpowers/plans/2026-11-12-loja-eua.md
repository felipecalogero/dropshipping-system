# Loja EUA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar a loja Next.js do spec de 2026-11-12: vitrine em inglês, checkout em dólar, admin em português e envio à CJ em um clique, com o checkout público desligado.

**Architecture:** Regras de dinheiro, faixa e status ficam em funções puras, testadas sem banco e sem rede. Next.js só chama essas funções. A CJ e a Stripe entram por interfaces, com falso nos testes. O webhook é a única porta que marca um pedido como pago.

**Tech Stack:** Next.js (App Router), TypeScript, PostgreSQL, Prisma, Vitest, Stripe API em `usd`, Resend, Docker Compose.

## Global Constraints

- Mercado: 50 estados dos EUA e DC. Espanha, Reino Unido, Brasil e o resto da UE ficam de fora.
- Loja em inglês. Admin em português. Moeda cobrada: USD, duas casas, exemplo `$48.00`.
- Frete da página de produto não mostra valor. O frete entra no checkout, cotado na CJ, sem acréscimo.
- Só produto com estoque em armazém dos EUA. Envio da China não é oferta.
- Sobra mínima para publicar: US$ 8,00 (800 centavos). Sobra para anúncio: US$ 39,00 (3900 centavos).
- Faixas de total (preço + frete), em centavos: cama 3500–6900, transporte 3000–6500, alimentação 1500–2800, higiene 2900–6900, organização 2000–4900.
- Fórmula: receita = preço + frete; custo_fornecedor = custo CJ + frete; sobra = receita − custo_fornecedor − 5,99% da receita − US$ 0,10 − 3% da receita − 3,5% do custo_fornecedor.
- Exemplo travado: custo 2000, frete 800, preço 4900 → receita 5700, sobra 2280. Esse produto não é elegível a anúncio.
- Preço proposto: meio da faixa; se a sobra ficar abaixo de 800, desce até o mínimo; se nem o mínimo passar, o produto não entra.
- CEP de referência: `64108`. Quantidade máxima por item: 10. Checkout de convidado.
- Checkout público começa desligado. Vitrine abre. Nenhum pedido é criado enquanto o interruptor estiver desligado.
- Só o webhook da Stripe com assinatura válida marca `paid` / `confirmed`. Redirecionamento do navegador não marca pago.
- Webhook repetido com a mesma referência não cria outro pedido nem outro e-mail.
- Clique para a CJ muda o cliente para Processing e não envia e-mail. Sem saldo na CJ, o interno permanece `paid`.
- E-mails: Order confirmed, Shipped, Delivered, Cancelled, Refunded. `problem` não envia e-mail.
- A página do pedido e os e-mails não contêm fornecedor, custo, margem, nota interna nem status interno.
- Sem avaliação, nota, quantidade vendida ou depoimento sem pedido real. Sem contador falso e sem selo de mais vendido.
- Pixel de anúncio ausente antes do aceite dos cookies. A loja não liga campanha.
- A primeira versão não chama a API de reembolso, não converte real em dólar e não pré-estoca.
- Primeira leva: oito rascunhos inativos. Não há teto de oito no admin.

```ts
type ContributionInput = {
  priceCents: number;
  shippingCents: number;
  supplierCostCents: number;
  stripeRateBps?: number;
  stripeFixedCents?: number;
  fxReserveBps?: number;
  iofBps?: number;
};

export function contributionCents(input: ContributionInput): number {
  const stripeRateBps = input.stripeRateBps ?? 599;
  const stripeFixedCents = input.stripeFixedCents ?? 10;
  const fxReserveBps = input.fxReserveBps ?? 300;
  const iofBps = input.iofBps ?? 350;
  const revenue = input.priceCents + input.shippingCents;
  const supplier = input.supplierCostCents + input.shippingCents;
  const stripe = Math.round((revenue * stripeRateBps) / 10_000);
  const fx = Math.round((revenue * fxReserveBps) / 10_000);
  const iof = Math.round((supplier * iofBps) / 10_000);
  return revenue - supplier - stripe - stripeFixedCents - fx - iof;
}
```

- [ ] **Step 3: Write minimal implementation**

O meio da faixa de cama é o total 5200. Com frete de 800, o preço proposto é 4400. O exemplo de 4900 no spec continua válido: é um preço dentro da faixa, e a ativação dele é o segundo teste. O automático oferece o meio, não o 4900.

```ts
import { contributionCents } from "./money";

export type Category = "bed" | "travel" | "feeding" | "grooming" | "home";

const BANDS: Record<Category, { min: number; max: number }> = {
  bed: { min: 3500, max: 6900 },
  travel: { min: 3000, max: 6500 },
  feeding: { min: 1500, max: 2800 },
  grooming: { min: 2900, max: 6900 },
  home: { min: 2000, max: 4900 },
};

type Settings = { minContributionCents: number; adContributionCents: number };

export function proposePriceCents(
  category: Category,
  supplierCostCents: number,
  shippingCents: number,
  settings: Settings,
): number | null {
  const band = BANDS[category];
  const midTotal = Math.round((band.min + band.max) / 2);
  const candidates = [midTotal - shippingCents, band.min - shippingCents];
  for (const priceCents of candidates) {
    if (priceCents <= 0) continue;
    const total = priceCents + shippingCents;
    if (total < band.min || total > band.max) continue;
    const contribution = contributionCents({
      priceCents,
      shippingCents,
      supplierCostCents,
    });
    if (contribution >= settings.minContributionCents) return priceCents;
  }
  return null;
}

type GateInput = {
  category: Category;
  priceCents: number;
  shippingCents: number;
  supplierCostCents: number;
  usStock: number;
  photoConfirmed: boolean;
  hasQuote: boolean;
  settings: Settings;
};

function inBand(input: GateInput): boolean {
  const total = input.priceCents + input.shippingCents;
  const band = BANDS[input.category];
  return total >= band.min && total <= band.max;
}

export function canActivate(input: GateInput): boolean {
  if (input.usStock <= 0 || !input.photoConfirmed || !input.hasQuote) return false;
  if (!inBand(input)) return false;
  return (
    contributionCents(input) >= input.settings.minContributionCents
  );
}

export function adEligible(input: GateInput): boolean {
  if (!canActivate(input)) return false;
  return contributionCents(input) >= input.settings.adContributionCents;
}
```
